## 1. 研究問題與兩個假設

**問題**：模型答對「背過的題」時，走的是不是一條與「本來就好猜的題」不同的內部路？

上一期（v0.7）只用觀察，這一期做干預：**弄壞、貼回去、量恢復**（patching）。

- **H_mem**：被還原的成分帶著背過的續文 → 抬高 p(gold)。
- **H_pred**：被還原的成分帶著讓續文好猜的上文線索 → 也抬高 p(gold)。

兩者同號（N-f.2）——所以單一出口分不開，識別靠**跨條件恢復對比＋溯源軌**（§7）。

## 2. 程序（主結構，M3 單一化後）

- **單 donor 腐蝕-恢復**：STR 式單 token 真詞腐蝕＋強度校準（R2）；
  patch 位置＝cue 鄰域、先單層帶（R4）。
- **主要行為終點**：Δ teacher-forced gold log-prob，**起手窗＝gold 前 2 個 token**；
  恢復比例 R = (Y_patched − Y_corrupted) / (Y_clean − Y_corrupted)，分子分母同窗（M1）。
  終點理由之一（N-f.1，寫死）：熵是詞彙置換不變的、gold log-prob 不是——
  換終點是**嚴格增益**，不是改寫法。
- **共同主出口（雙軌）**：①起手窗 gold 恢復（teacher-forced）；
  ②自由續寫溯源（L0 receiver 的 frac_present 下降）。兩者是**不同泛函**
  （把答案遞給模型問它信不信 vs 要它自己寫出來——N-f.4，R9 的新依據）。
- 續航窗（第 3 token 起）**僅描述性**（R3）。
- **規格補完（2026-08-21 深夜，先於任何因果量測；凍結時遺漏的量測參數，補定非更改）**：
  溯源軌的 frac_present 一律用 **6 詞窗、stride 4、60-token 貪婪續寫**
  （v0.7 `check_l5_novelty.py` 與 [redacted: internal workflow note] 的既有慣例）；
  基線與主實驗同參數，基線工件＝`results/causal/provenance_baseline.json`。

   **冒煙檢查（G1，v2.6 重述版）**：~~原版「噪音門檻由同題不同 seed 的重複

   ——分母隨機且近 0 有密度 ⇒ R 無有限變異數）**：保留題上把所有 patch 的
   (Δs, ΔY) 混合擬合 ΔY ~ f(Δs)，**殘差尺度用 MAD 穩健版（凍結）**，對照
   數值底線。**兩層讀數（兩種擬合都跑）**：**G1-a**＝pooled 殘差 ≈ 底線 →

   不可識別**；任一帶有額外結構即通過並記錄該帶。

## 9. 保留集與併池

- **12 題：新 L0 5＋L0M 4＋L0P 3**；造好即凍結為 holdout，永不進主裁決。
- 硬約束：①**4 個 L0M 保留題必須是 L0 保留題的雙胞胎**（ρ 唯一來源）；
  ②**G-link 不掛 L0P**（其溯源出口為構造性的零：pythia-1.4b 16/18、OLMo 18/18）。
- 變異數模型：`y[c,r,i] = mu[c,r] + b[i] + e[c,r,i]`，四個 Pythia run 共享同一
  b[i]。**跨 run 併池不為 σ 加自由度**（五模型買外部效度不買精度）；
  跨條件併池先過同質性檢查（變異數比 > 2 → 不併，逐條件報 σ）；
  跨家族只併標準化尺度因子；L0M 與其來源 L0 不當兩個獨立 df。
- 精度承諾：12 題 → σ CI 2.07×、題庫規模不確定 4.3×——
  足以分辨 30 vs 150 題，不足以分辨 30 vs 60（可能需一輪小迭代，照實預告）。
