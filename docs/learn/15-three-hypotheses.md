# 15. 三個假說：閘門／工作點／雙迴路（Gate / Regime / Module Hypotheses）

**一句話白話版**：模型接續一段話，內部一定發生了「某件事」——這不是問題（同一條前向傳播，答案必然「有內部歷程」）。真正的問題是：這件事在「回憶」和「創造」時，是同一套機器切換了一個開關（閘門）、還是同一套機器只是踩在不同的舒適區（工作點）、還是根本是兩套不同的機器（雙迴路）？

**為什麼本研究用得到**：這是整個研究要回答的核心問題（正文「為什麼要問這個問題」一節）。六層任務階梯（卡12）、每個量測工具（logit lens、熵、KL 收斂深度、gold_logprob、表徵分離度，卡06–10）存在的唯一理由，就是收集足夠的證據去區分這三個假說——不是隨便選一個信仰，是看數據站在哪一邊。

**再深一點**：三個假說對「內部訊號長什麼樣」給出不同、可被檢驗的預測。

- **閘門假說（gate）**：內部存在一個訊號，把「提取出來的」和「編出來的」明確標記開來。預測：某個方向或某層表徵上，回憶題和創造題呈現**離散、有邊界**的分野，不是連續滑動。文獻類比是「reality monitoring」（模型分辨自己說的跟輸入給它的，arXiv:2607.23927）與「global workspace／J-space」（Gurnee et al. 2026-07，一小組「可報告、可控制」的特權表徵）。
- **工作點假說（regime）**：不是有沒有開關，是同一套聯想提取機器，在生成新想法時只是落在一個**弱吸引子**（好幾個候選答案勢均力敵，模型比較猶豫）的工作點上。預測：從 L0 到 L5 內部訊號應該**平滑漸變**，沒有斷點——這正是我們第一批 pilot 數據看到的模式（`docs/PROCESS_LOG.md` 第十二步）：熵一路爬升、記憶強度與收斂深度有連續劑量反應（rho=−0.37）。理論靠山是聯想記憶的數學框架（arXiv:2505.21777：diffusion 模型裡不完美的檢索狀態是生成能力的起點；Kamb & Ganguli, ICML 2025：創造力可預測成完美檢索被局部性破壞後的必然副產品，r²≈0.95）。
- **雙迴路假說（module）**：回憶和創造是**可分離**的兩套電路，只是共用同一具身體。證據標準最嚴：不能只看相關，要看**因果**——能不能找到一個介入手段（例如 activation patching，把某一層的內部向量替換掉或關掉，卡20預告），只損傷回憶不損傷創造。arXiv:2510.03366《Disentangling Recall and Reasoning》已示範這種雙重解離：關掉回想迴路，事實提取掉 15%，推理無損——這篇論文的方法正是 README 明確點名要參照的模板，只是把第二軸從「推理」換成「創造」。

三者不是互斥的：能區分它們的關鍵在證據的**形狀**——連續漸變支持工作點；離散跳變或可定位的標記訊號支持閘門；因果可分離（能單獨損傷一邊而不傷另一邊）才支持雙迴路。目前只有相關性層級的量測工具（卡06–10），撐不起雙迴路假說的因果標準，這正是卡20預告的 activation patching 要補的洞。

**在我們的程式碼／數據裡**：三個假說的原始表述見正文「為什麼要問這個問題」一節與本卡；`harness/run_pilot.py` 的 `position_profile()`、`harness/analyze_pilot.py` 的 `separation_curve()` 能提供的是相關性層級的證據，足以支持或動搖工作點假說（漸變 vs 斷裂）與閘門假說（分離度是否呈離散分群），但雙迴路假說需要因果介入工具，目前 harness 裡還沒有——這是發表後的因果階段（卡20）要接手的下一步。

**常見誤解**：
1. 「反正模型內部一定有東西在發生，這題目根本沒得問」——`README.md` 開宗明義排除了這個誤解：問題從來不是「有沒有共同內部現象」，而是這個現象的**形狀**是閘門、工作點、還是雙迴路，三者對可觀測數據的預測不同，是可以被裁決的。
2. 「找到一個方向能把回憶和創造的表徵分開，就證明是雙迴路假說」——不夠。表徵能被分開（卡10）只代表兩者在幾何上不同，這跟工作點假說完全相容（不同工作點的內部狀態本來就會落在表徵空間的不同區域）；要證明雙迴路，必須做因果介入。

**答辯模擬題**：
- Q：如果數據顯示熵從 L0 到 L5 平滑上升，這樣就能排除雙迴路假說嗎？
  A：不能直接排除，只能說相關性證據比較支持工作點假說；要排除雙迴路假說，必須做因果介入實驗（例如關掉某個子電路看回憶和創造是不是同時受損），這是目前量測工具還做不到、留給下一步 activation patching 的工作。
- Q：這三個假說裡，你們比較相信哪一個？
  A：目前第一批 pilot 數據（平滑的熵階梯、記憶強度與收斂深度的連續劑量反應）比較支持工作點假說；現在已有兩個獨立血統模型的相關性證據（混組版 Pythia rho=−0.289／p=0.036；OLMo-2 rho=−0.505／p=8.4e-05；更穩健的組內版見卡 16——五模型 −0.53/−0.34/−0.69/−0.42/−0.86；熵效應量 −0.63／−0.85），方向一致，但表徵分離的峰值位置兩模型並不完全相同。仍缺的是因果介入（activation patching），所以還不能升級成機制主張——正式結論要等因果介入工具跟上之後才能下。
