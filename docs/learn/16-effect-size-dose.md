# 16. 效應量與劑量反應（Effect Size & Dose-Response）

**一句話白話版**：rank-biserial 是「隨機各從兩組抓一個數字，誰比較大」的白話勝率，範圍 −1 到 1；Spearman 相關（rho）是「兩個東西的名次排序是否一起變動」的白話相關係數。樣本很小的時候（我們 pilot 一個條件常常只有 11–24 題），與其死盯著 p 值有沒有低於 0.05，不如老實報告「效應有多大、往哪個方向」。

**為什麼本研究用得到**：pilot 階段每個條件的題數都很少（L0 只有 17 題、L4 只有 12 題），p 值在這種樣本量下天生就不穩定——同一個真實效應，換一批題目重跑，p 值可能從 0.03 跳到 0.2，不代表效應消失了。效應量（如 rank-biserial）不會因為 n 小就自動縮水，它量的是「差異有多明顯」而不是「有沒有足夠證據拍板定案」，這正是 pilot 階段該報告的東西——先看方向和大小是否符合假說，之後再用更大樣本去確認統計顯著性。

**再深一點**：rank-biserial 的定義是 `(greater − less) / (n_a × n_b)`，其中 greater 是「a 組某個數大於 b 組某個數」的配對次數，less 反過來算。直覺理解：隨機各從 a、b 組抓一個數字比大小，a 贏的機率減掉 b 贏的機率。值為 +1 代表 a 組每個數字都大於 b 組每個數字（完全分開），0 代表兩組完全沒有系統性差異。Spearman rho 則是先把兩個變量各自轉成名次（rank），再對名次算相關係數——好處是不假設兩者是直線關係，只要求「一個變大、另一個傾向跟著變大或變小」，對離群值也比皮爾森相關穩健，很適合「記憶強度」這種尺度可能不均勻的變量。p 值回答的是「如果真實世界沒有這個效應，看到眼前這麼極端的數據的機率」——這個機率的估計本身在小樣本下誤差很大，所以在報告裡效應量的大小與方向，比單看 p 值有沒有過門檻更值得信任。

**在我們的程式碼／數據裡**：`harness/analyze_pilot.py` 的 `rank_biserial(a, b)` 函式（第 24–31 行）算出各條件對比的效應量，寫進 `results/analysis_EleutherAI_pythia-1.4b.json` 的 `contrasts_rank_biserial`。例如 `L1_vs_L4` 的 `final_entropy` 效應量是 **−1.0**：把 L1（回答常識）和 L4（強迫混搭）的熵值兩兩配對比較，L1 永遠比 L4 低——完全一致的方向，符合「創造比回憶更猶豫」的假說。劑量反應的計算在 `harness/analyze_pilot.py` 第 129–143 行，用 `scipy.stats.spearmanr` 算「記憶強度」（`gold_logprob_per_token`，模型對原文逐字的信心，越接近 0 代表越熟）和「收斂深度」（`depth_tau_0.1`，數字越接近 1 代表要用到越後面的層才鎖定答案；這裡採用的是 tau=0.1 版本，換成 tau=0.05／0.5 或 argmax，效應方向與量級都會跟著晃動——收斂深度的效應對門檻敏感，細節見卡 11）之間的相關，結果寫進 `analysis["dose_response"]`：**rho = −0.289，p = 0.0355，n = 53**（混組 L0+L0N+L1；v2.1 重建對照組後，這個混組相關比舊版弱了不少，見下方「常見誤解」）——記憶越強（gold_logprob 越接近 0），收斂深度越低（越早在淺層就定案）。這正是「劑量反應」字面上的意思：記憶強度像藥物劑量，內部多早收斂像身體反應，程式裡這個變量本身就直接叫 `dose_response`。

**常見誤解**：
1. 「混組 rho 只有 −0.29，等於沒有效應」——這個數字本身確實比較脆弱，得老實講：v2.1 重建對照組之後，混組（L0+L0N+L1，n=53）的相關從舊版的 −0.37 弱化到 −0.29，p 值也從 0.007 掉到 0.0355——只勉強壓在 0.05 門檻之下，換一批題目重跑很可能就不顯著了，不該拿它單獨扛「劑量反應」這個結論。真正穩健、也是本研究實際依賴的證據是**組內**（within-condition）分析：五個模型各自只看 L0（逐字背誦）條件內部的 gold_logprob 對 depth_tau_0.1 相關，得到 −0.53、−0.34、−0.69、−0.42、−0.86（Pythia-1.4B 是其中的 −0.69，見上方數據）五個同方向的值，三個達到 p < .05——組內相關才是「記憶越強、收斂越早」的主要支撐，混組數字只是附帶提及的較弱旁證，不是拿來扛結論的支柱。
2. 「小樣本就該追求更嚴格的 p 值門檻才保險」——反過來想：小樣本下 p 值本身的抽樣誤差更大，把信心全押在「p 有沒有小於 0.05」上更容易被單次抽樣的運氣誤導；效應量至少讓你知道即使這次 p 值不漂亮，效應的方向和量級長什麼樣子，可以在下一批更大樣本裡驗證是否重現。

**答辯模擬題**：
- Q：你們的 dose_response 只有 n=53，這麼小的樣本算出來的相關係數能信嗎？
  A：混組（n=53）這條線其實是研究裡相對脆弱的一環——v2.1 對照組重建後 p 值從 0.007 掉到 0.0355，只是勉強壓在 0.05 之下，換一批題目重跑很可能就不顯著，我們不會拿它單獨扛「劑量反應」的結論。真正扛住結論的是組內分析：五個模型各自在 L0 條件內部算出 gold_logprob 對 depth_tau_0.1 的相關，得到 −0.53、−0.34、−0.69、−0.42、−0.86 五個同方向的值，三個達到 p<.05——這才是我們主張「記憶越強、收斂越早」的主要證據，混組數字只是附帶提及，不會拿 53 個點就直接宣稱因果。
- Q：為什麼不用皮爾森相關（Pearson correlation），非要用排序的 Spearman？
  A：因為我們不確定「記憶強度」和「收斂深度」之間是不是直線關係——例如記憶強到某個程度之後，收斂深度可能提早觸底、不再繼續往下降；Spearman 只要求「一個變大、另一個傾向同向變動」，不假設線性，也比較不怕少數極端值（比如某題模型硬是沒背熟）把相關係數拉歪。
