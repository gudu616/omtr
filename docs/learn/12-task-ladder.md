# 12. 任務階梯 L0–L5（Task Ladder）

**一句話白話版**：把「叫模型做的事」按「要不要用到記憶」排成一道階梯，從 L0「一字不差接出背過的名句」爬到 L5「發明一個訓練資料裡查無的新東西」；每一階都有一個客觀的正確答案判定依據（ground truth）。

**為什麼本研究用得到**：本研究要看的是內部訊號隨著任務越來越不靠記憶，是漸變還是斷裂——這需要一把有刻度的尺，不能只有「回憶」「創造」兩個極端點。兩點連線永遠是直線，看不出漸變還是某處突然斷開；六階才能畫出一條真正的曲線（見卡15的假說之爭）。

**再深一點**：

| 層 | 定義 | ground truth |
|---|---|---|
| L0 | 逐字背誦（公版名段接續） | infini-gram count ≫ 0 |
| L0N | 對照組（卡11）：同構冷門段落 | infini-gram count ≈ 0 |
| L1 | 事實回想（實體→屬性） | 唯一正解 |
| L2 | 已知內容改寫 | 語意保真、字面偏離 |
| L3 | 已知形式 × 新內容 | 形式合規 |
| L4 | 遠距概念強制合成 | 指定 blend 對 |
| L5 | 開放新想法 | 事後 infini-gram 查無 |

（除 L0N 外的六列取自 `README.md`「任務階梯」；L0N 是對抗式審查後加入的對照，不在原表但實際跟 L0 並排跑。）

L0/L0N 用「裸接續」（bare continuation）——不加任何說明文字，直接把切好的原文前半段丟給模型接，因為續寫本來就是 base 模型最擅長的模式。L2–L5 套上「鷹架」（few-shot scaffold，卡05）：`battery/scaffolds_final.json` 裡 L2/L4/L5 各放兩則、L3 放四則跟正式題目無關的示範（例如 L2 用「腳踏車為什麼不會倒」「燈塔為什麼看得到」教格式），讓不聽指令的 base 模型從範例裡模仿出「這是要回答問題」，而不是靠讀懂指令；L1 不套鷹架，只在 cloze 提示前面墊一段語意惰性前言（見下段 `L1_PREAMBLE`）。

這兩種家族的 prompt 長度天生差很多，直接比「第幾層收斂」會混進「prompt 越長要處理的東西越多」這個額外變因。分兩層處理：L1 的 cloze 提示天生極短（例：`"Bees move from flower to flower carrying a fine powder called"`），所以另外墊一段語意惰性前言（`harness/build_battery_v2.py` 的 `L1_PREAMBLE`，程式註解寫明「把 cloze 提示墊到接近 L0 的 token 預算」），讓 L0（prompt token 中位數 54）、L0N（60）、L1（50）落在同一量級；L2–L5 的鷹架天生就長很多（中位數 201–408 token，兩則範例需要篇幅才能教會格式），這個結構性落差不硬壓平——壓到跟 L0 一樣短，鷹架就教不會格式了。決策記錄的作法是「跨家族比較靠 per-token 聚合＋covariates」：不強求所有層等長，而是分析時把 token 數當共變量（covariate，白話：分析時順手控制掉的干擾變數）控制，比較每個 token 位置而不是整段話的平均值。

**在我們的程式碼／數據裡**：`battery/battery.json` 的 `items` 陣列，每筆的 `level` 欄位就是 L0/L0N/L1–L5；`harness/build_battery_v2.py` 組裝整份 battery，並用 `assert` 檢查每個鷹架模板都含 `{ITEM_PROMPT}` 占位符；`harness/build_l0_gutenberg.py` 的 `TOTAL_WORDS=88`、`SPLIT_AT=44` 定義 L0 的機械切分規則，`build_l0_controls.py` 沿用同一組常數建構 L0N。最終規模：103 項（L0×20＋L0N×11＋L1 cloze×24＋L2–L5 鷹架×48）。

**常見誤解**：
1. 「L0–L5 是難度階梯，L5 比 L0 難」——不是難度階梯，是「靠記憶的程度」階梯。L1 事實回想對模型可能比 L4 強迫混搭更難，因為 L4 只要求把指定的兩個領域接起來、不要求唯一正解，L1 卻要求唯一正解。
2. 「鷹架的 few-shot 範例會把答案帶壞，等於在教模型抄範例」——鷹架教的是格式，不是內容；`scaffolds_final.json` 裡的範例主題跟任何正式題目都無關，就是要避免內容洩漏。

**答辯模擬題**：
- Q：為什麼不是只做「回憶」和「創造」兩題就好，何必分六層？
  A：兩點連線永遠是直線，看不出「漸變」還是「中間某處突然斷開」——這正是本研究要裁決的問題，至少要有中間層才能畫出形狀。
- Q：L2–L5 的 prompt 比 L0 長好幾倍，這樣比較不是不公平嗎？
  A：長度差異是鷹架格式無法避免的結構性落差，我們不假裝它不存在，而是分析時把 token 數當共變量控制，並改用「每個 token 位置」的聚合方式比較，而不是直接比較整段話。
