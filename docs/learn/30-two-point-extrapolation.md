# 30. 外推兩點法（Two-Point Extrapolation，v2.17 制度）

**一句話白話版**：如果你只量過一個小朋友長高的速度，就想拿去預測一個成年人身高會怎麼變，那個推算通常不可靠——因為「小朋友」跟「成年人」可能根本不是同一條成長曲線。要讓一個跨尺寸的推算能被信任，至少要在「差一個量級」的兩個點上都真的量過，看看它們是不是真的走同一條線；只量一個點，你連「這條線存不存在」都不知道。這就是本研究新增的一條制度：**任何要跨模型外推的參數，必須在相隔一個數量級的兩個模型上都量過，才准拿去承載判定。**

**為什麼本研究用得到**：這條規矩是本研究自己付出代價換來的。同一個晚上，團隊裡不只一個人犯了同一種錯——都是「只在一個模型上量過某個參數，就把它當成放諸各模型皆準的常數」。最戲劇性的一次是卡 29 講的共模抵消事件：1b 量到 DiD 偏差 0.011 nats，理論部因此判定 fp16 可以放心用；後來 1.4b 補量，同一個量跳到 0.240——整整 22 倍。修法不是「量更多次就好」，是明文立法：任何要外推到其他模型規模的參數，起碼要有兩個差一個量級的模型的實測數字撐著，少於兩點就不准拿去做判定依據。

**再深一點**：為什麼「兩個點」是門檻，而不是「量一個大概就好」？因為單一個點只能告訴你「這一個模型上量到多少」，沒辦法告訴你「這個量隨模型大小怎麼變」——同一個數字既可能是「所有模型都差不多」，也可能是「剛好量到曲線很平的那一段」，光看一個點分不出來。要看出「有沒有隨大小系統性變化」，至少要兩個點才能畫出一條線的方向（哪怕只是方向，不是完整曲線），而且這兩個點要離得夠遠（相隔一個數量級，比如 1B 級跟 10B 級模型），太近的兩個點測到的可能只是雜訊。

這條規矩不是憑空立的，它同一個晚上被同一種錯誤觸發了兩次，理論部自己在報告裡點名：一次是卡 29 那個 dtype 偏差外推事件；另一次是**裝置成分**（同一個算術用 CPU 跑跟用 GPU 跑會不會有差）的外推——1b 到 1.4b 量到的「換裝置造成的偏差」長了 9.4 倍，理論部原本想比照辦理，把這個倍率外推到 2.8b 身上，但寫報告時自己抓到：「這正是 v2.17 剛立法禁止的那一步，而且我就是那條法的觸發者之一」，改成在 2.8b 上直接量它自己唯一量得到的裝置對照，而不是套用別的模型量到的倍率。

一個更值得記住的細節：J4 最初推的「最壞情況」界線是 0.236，後來 1.4b 實測是 0.2396——兩個數字幾乎完全命中。回頭看才發現：不是那個推算界線一開始就很準，是**第一個補量點（1b）剛好落在曲線很平的那一段**，讓「用單點外推」這件事看起來安全，其實只是運氣好。這正是為什麼「兩點」比「一點看起來合理就先用」可靠——一個點永遠沒辦法告訴你自己是不是踩在平坦區。

**在我們的程式碼／數據裡**：`planning/DESIGN_PROPOSAL_v2.2_rulings.md`「v2.17–v2.18 增補裁決」段（規則原文：「新制度：跨模型外推參數須在相隔一個量級的兩模型上量過方得承載判定」）；被這條規則抓到的兩個實例都在 `theory_v3_final.md` 附錄 J：J7（dtype 偏差，1b vs 1.4b，0.011→0.240）與 §5.11.2（裝置成分，1b→1.4b 長了 9.4 倍，因此改在 2.8b 上直接量，不外推）。

**常見誤解**：
1. 「反正之後會補量，現在先用單點外推的數字趕快下結論沒關係」——不對，這條規矩正是為了防這件事：錯誤的推論一旦被寫進「定版裁決」，之後就算補量發現不對，也已經造成一次「用沒查證的東西下判定」的既成事實，這跟本研究「不讀全文不准判死」的紀律是同一種精神，只是換了「量測」這個領域。
2. 「單一個模型量到的數字如果看起來合理，就可以先當常數用」——「看起來合理」正是最危險的訊號，J4 最初推的最壞界（0.236）跟後來 1.4b 量到的實測值（0.2396）幾乎完全命中，正是因為第一個補量點剛好落在曲線很平的那一段，容易讓人誤以為外推安全。

**答辯模擬題**：
- Q：為什麼不乾脆規定「一律要五個模型都量過」，兩個點感覺還是很少？
  A：五個模型都量成本很高，窗口時間有限；「兩個相隔一個量級的點」是成本與風險的折衷——它擋不住所有外推錯誤，但擋得住本研究實測撞到的那種錯誤（單點外推、且低估了模型間的變化幅度），而且是本研究實際付出代價換來的門檻，不是憑空訂的安全係數。
- Q：這條規矩會不會太晚立？已經有結論建立在單點外推上了怎麼辦？
  A：兩個被抓到的案例都是解盲前、GPU 正式主實驗跑資料之前發現並修正的——dtype 偏差最後裁定四個裝得下的模型全部改用 fp32 直接跑（消滅這個不確定性，而非外推它），裝置成分則改成在 2.8b 上直接量。修法都發生在任何人看到真實裁決資料之前，所以立法晚不等於結論建立在未修正的外推上。
