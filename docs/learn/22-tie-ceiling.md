# 22. 同分天花板（Tie Ceiling：相關係數的可達上限）

**一句話白話版**：Spearman 相關比的是「排名」，但如果一組數據大量同分（一堆並列第一），排名根本排不開——這時不管另一個變量多完美地配合，相關係數在數學上就是到不了 ±1。這個「靠洗牌也永遠到不了的上限」就是同分天花板。

**為什麼本研究用得到**：我們的核心對比是「記憶組有劑量反應（OLMo 組內相關 −0.860）、對照組平坦（+0.07）」。但夜間拷問（R5）發現：對照組的深度值只有 2–5 個相異值、大量同分，它**可達的相關上限只有 0.671**——也就是說，就算對照組其實藏著完美的劑量反應,它在這把尺上最多也只能顯示 0.671，而 −0.860 這個數字在對照組任何資料排列下都不可能出現。拿 −0.860 跟 +0.07 並排比,等於讓兩隊跑不同長度的跑道再比成績。

**再深一點**：怎麼算天花板？把對照組的深度值（含所有同分）固定住，問「在所有可能的配對方式裡，|rho| 最大能到多少」——這只跟同分結構有關,跟實際數據無關,是純數學上限。更麻煩的是,我們用來檢定「兩組相關是否不同」的 Fisher-z 檢定,前提是兩個係數在同一把尺上;天花板不同=尺不同,所以檢定會**高估解離的幅度,高估多少未知**。誠實的處理不是撤回主張（方向仍然成立）,而是把天花板數字寫進稿件,讓讀者對照著讀。

**在我們的程式碼／數據裡**：計算在 `results/night/` 的 R5 一節（`R1_verification.md`）。關鍵數字：OLMo 對照組上限 0.671 vs 記憶組實測 0.860——受束縛,必須加但書;Pythia-1B 對照組上限 0.650 vs 實測 0.337——沒被束縛,這格是公平的。這一條提案已於 2026-08-21 經作者批准寫入正文（v0.5 §3 的同分天花板段，TL;DR 亦有回聲句）。

**常見誤解**：
1. 「同分是資料髒,清一清就好」——不對,同分是量測解析度的誠實反映（對照組的深度天生擠在幾個值上）,硬加雜訊拆散同分反而是造假。
2. 「有天花板=結果作廢」——不對,方向和顯著性都還在;天花板改變的是「解離有多大」的解讀,不是「解離存不存在」。

**答辯模擬題**：
- Q：你們自己承認對照組的尺有上限,那整個對比不就不公平?
  A：對,所以稿件把上限數字直接印出來,並且另做了「範圍配平」的補充比較（提案 1）;在配平後的公平比較裡,解離在 OLMo 仍然乾淨存活——結論縮小了範圍,但沒有消失。
- Q：這個問題是審查者抓到的還是你們自己抓到的?
  A：是我們夜間自我拷問抓到的,而且抓到時稿件已經凍結——我們選擇寫成再審提案走程序,而不是當作沒看見。這正是我們希望讀者用來評估其餘主張可信度的行為樣本。
