# 33. 盲推對答案：怎麼檢查一個「沒有標準答案」的決定

## 生活場景

兩個同學各自算同一題數學，**算完才准對答案**。如果兩人答案一樣——
要嘛都對，要嘛「各自獨立地錯到同一個地方」，而後者的機率小得多。
但如果是一個人先看了另一個人的答案再「檢查」，答案一樣就什麼都
證明不了——人看過答案之後，很難不被帶著走。

## 我們怎麼用它

位置檢定的規則書裡有兩條「怎麼定都說得通」的裁量決定（哪些模型算數、
用哪種洗牌法檢定）。寫規則的人自己提出：**請第二個人不要看我的理由，
自己從頭推一遍**。結果第二個人獨立推出了一模一樣的選擇——連「四個
模型裡三個是近親，實際獨立票數大約只有兩票」這個細節都各自算到。

## 為什麼這比「幫我看看有沒有錯」強

請人「看看有沒有錯」，對方是拿著你的答案找碴——你的框架已經先住進
他腦裡了。盲推是讓對方自己蓋一棟，再比對兩棟長得一不一樣。**能撞出
同一棟房子的，通常是地基本身，不是誰抄誰。**

## 附贈的教訓：模擬要模擬「估計量」，不是模擬「擔憂」

同一輪還抓到一個高級錯誤：有人擔心「窗」層級的干擾，就照「窗」去建
模擬——但真正的計算是在更細的「字」層級取平均。模擬了自己的**擔憂的
講法**，沒模擬自己**實際在算的東西**，數字就高估了三倍。
檢查法一句話：**動手模擬前先問「我的估計量實際在哪個顆粒度上運算？」**
