# 27. TOST 等價檢定（Two One-Sided Tests）

**一句話白話版**：考試沒考差（沒有顯著差異）不代表你真的跟滿分一樣強——可能只是這次題目太難、或樣本太少，測不出差別。**「沒有顯著差異」跟「相等」是兩件不同的事**，要證明「兩組幾乎一樣」，得反過來考兩次：先問「甲會不會比乙好一大截？」，檢定看能不能推翻；再問「乙會不會比甲好一大截？」，檢定也看能不能推翻。**兩次都被推翻，才能說「差距被夾在這個範圍內，幾乎相等」**——這就是 TOST（兩個單尾檢定）名字裡「兩個」的由來。

**為什麼本研究用得到**：因果階段的裁決表裡有一格叫 R-entangled（記憶跟可預測性糾纏、分不開），這格要求的不是「沒差」，是「差距量到落在一個事先訂好的範圍內」，用的正是 TOST。如果只看「不顯著」，那可能只是樣本太少測不出來，不能拿來說「兩者相等」——這正是本研究一路很在意的分寸：沒證據不等於有反證。

**再深一點**：TOST 的邏輯拆開來看：設一個等價邊界（多小的差距才算「幾乎一樣」），做兩個單尾檢定——一個檢定「真差距 ≥ +邊界」，一個檢定「真差距 ≤ −邊界」，兩個虛無假設都要被拒絕，才敢說「差距落在 (−邊界, +邊界) 之間」。這種「兩個都要過」的連言，剛好是本研究整套統計裡少數**不需要多重比較校正**、水準恰好等於 α 的地方（跟卡 24 §6 決策表裡另一個被擋下的連言不一樣——那個是虛無率會被連言乘出戲劇性的縮小，這個 IU 檢定〔交集聯集檢定〕的虛無假設本身就是聯集，所以不會有那個問題）。

邊界怎麼訂很關鍵，訂錯兩邊都會出事：**訂太窄，幾乎不可能通過**（嚴格到沒有意義，任何一點點雜訊都會讓你過不了關）；**訂太寬，通過了也沒有意義**（「差距小於 1.2 個標準差」幾乎排除不掉任何東西，通過了等於沒講）。本研究解盲前用模擬掃描了不同邊界的檢定力，找到「有力又有意義」的那個點：邊界 0.7σ 時，每個模型家族需要大約 24 題才夠。也因此發現 L0N（真英文、語料不存在的對照組）在任何測過的邊界下都撐不起等價判定，所以 R-entangled 只能掛在 L0P 跟過 ρ 閘門的 L0M 上，不能掛在 L0N 上——單家族樣本太小，扛不起這格。

**在我們的程式碼／數據裡**：`planning/CAUSAL_PREREG_v1.md` §6（TOST 等價邊界：凍結時由量到的 MDE〔最小可偵測效應〕推導寫死）；`planning/office_reports/theory_v2_addendum.md` §3.4（M6：掃描等價邊界寬度、找出「有力又有意義」的那個點，附完整檢定力表）；模擬腳本 `theory_v2_tost.py` / `theory_v2_sim.py`。

**常見誤解**：
1. 「p > 0.05 就代表兩組一樣」——不對，那只代表「沒有偵測到差異」，可能是真的一樣，也可能只是樣本不夠。TOST 要求先訂一個「多小才算一樣」的邊界，再證明差距真的落在那個邊界內，這是完全不同的兩件事。
2. 「TOST 通過等於嚴格證明相等」——不對，通過只代表「差距落在邊界內」，邊界怎麼訂決定這句話多有意義；邊界訂得太寬，通過了也沒有意義。

**答辯模擬題**：
- Q：你們怎麼證明兩個條件「糾纏、分不開」，而不是「其實有差，只是沒測出來」？
  A：不是靠「不顯著」下這個結論——那正是統計初學者常犯的錯。我們用 TOST，先凍結一個等價邊界（由冒煙量到的 MDE 推導），對「差距 ≥ 邊界」跟「差距 ≤ 負邊界」兩個假設分別做單尾檢定，兩個都被拒絕才算通過，這比「不顯著」嚴格得多。
- Q：邊界怎麼訂？你們有沒有可能訂一個很寬的邊界讓自己好過關？
  A：沒有。邊界是解盲前用模擬蒐集的檢定力表訂的——太窄幾乎不可能通過、太寬通過了沒意義，我們選的是「讓等價出口既有力又有意義」的那個點（0.7σ，配 n≈24），而且訂的時間點在看到任何真實資料之前。
